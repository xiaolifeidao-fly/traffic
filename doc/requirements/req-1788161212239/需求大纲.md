# 新管理端分配配置支持 allowAssignTime

## 需求背景与目标

新管理端的“人工商品管理 -> 分配策略 -> 分配配置”目前无法维护 Barry 分配配置中的 `allowAssignTime`。Barry 的分配配置 DTO、数据库实体及取单逻辑已经具备该字段，当前缺口位于 Phoenix Go 代理契约和管理端表单。

本需求补齐 `allowAssignTime` 的查询、保存和页面回显链路，使管理员可以在新增、编辑分配配置时设置或清空允许分配时间。

## 范围与不做的事

### 交付范围

- Phoenix Go 代理在查询和保存分配配置时透传 `allowAssignTime`。
- 新管理端分配配置新增、编辑及查看表单支持该字段。
- `allowAssignTime` 按可选日期时间处理，编辑时回显已有值，并允许清空。
- 补充代理 DTO 的序列化、反序列化验证及管理端相关回归验证。

### 不做的事

- 不修改 Barry 分配配置实体或数据库表结构。
- 不调整 Barry 已有分配、取单及时间过滤逻辑。
- 不改动人工商品管理中与分配配置无关的策略字段。
- 不生成独立原型或其他需求附件。

## 关键约束

- 字段名称固定为 `allowAssignTime`。
- 时间传输格式必须与 Barry 当前接口格式一致，Phoenix 只负责兼容并完整透传。
- 字段为空时必须兼容历史配置，不得导致查询、编辑或保存失败。
- 管理端保存成功后的本地数据应以接口返回结果为准。
- 任务起始阶段为 `development`，负责人随需求保持未指派。

## 验收标准

### Phoenix 代理契约

- 查询 `/barry/assign-configs` 时返回 Barry 提供的 `allowAssignTime`。
- 新增和编辑保存分配配置时，将 `allowAssignTime` 原样传递给 Barry。
- 字段为空时保持兼容，不影响历史配置。
- DTO 序列化和反序列化测试通过，时间格式与 Barry 当前接口一致。

### 新管理端

- 新增和编辑分配配置时均显示 `allowAssignTime` 日期时间控件。
- 新增保存能够提交所选时间。
- 编辑已有配置能够正确回显并更新时间。
- 清空后能按接口约定提交空值，历史空值配置可以正常打开。
- 保存成功后的本地列表数据与接口返回值一致。
- 既有分配配置字段的展示、编辑和保存不受影响。

## 待确认问题

无。用户已确认 `allowAssignTime` 按可选日期时间字段实施；具体序列化格式以 Barry 当前接口为准。
