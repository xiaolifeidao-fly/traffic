# 新管理端工作台UI优化

## 摘要

对管理端「新工作台」页面（`phoenix/client/manager/src/app/(console)/manager-dashboard/`）做整体视觉样式与交互体验优化，不改变现有数据字段、接口和业务逻辑。范围覆盖整个工作台页面：统计卡片网格、商品桥接器统计表格、卡片编辑配置抽屉、速度趋势图、加载/空/异常状态。先建立统一视觉规范，再依次落地到各区域。验收以"视觉风格统一、无功能与数据回归"为口径。

## 需求背景与目标

管理端工作台核心页面 `ManagerDashboardPanel.tsx` 是单个约 4266 行的组件，历史上多次迭代堆叠，样式散落在大量内联 `style` 和零散 `manager-*` class 中，视觉不统一（间距、圆角、字号、配色无规范），交互体验（配置抽屉、加载态、表格操作）也有提升空间。本次需求目标是在不动业务逻辑和数据结构的前提下，系统性优化整个工作台的视觉样式与交互体验。

## 范围与不做的事

**范围内**：
- 顶部统计卡片网格的视觉与响应式布局
- 商品桥接器统计表格的视觉与交互
- 卡片编辑配置抽屉的交互体验
- 底部速度概览趋势图的视觉
- 加载中/空数据/异常状态的视觉统一

**不做**：
- 不改变任何后端接口、数据结构、取数逻辑
- 不新增/删除统计卡片或统计维度
- 不改变配置项的持久化方式（`DashboardCardConfig`）
- 不改变图表库、轮询/刷新机制、错误汇总判断逻辑

## 关键约束

- 所有优化必须保证原有数据展示、实时刷新、配置读写功能不回归。
- 视觉规范需先行统一（任务1），后续任务基于该规范落地，避免各区域各自为政。
- 不引入新的第三方 UI 库或图表库，在现有技术栈内优化。

## 验收标准

- 页面全部卡片、表格视觉风格统一（间距、圆角、字号、配色一致），无内联样式冗余堆砌。
- 常见分辨率（1440px、1920px，窗口缩小到约 1280px）下布局不错位、不溢出。
- 配置抽屉、表格排序/删除等交互操作路径清晰，反馈及时。
- 加载中/空数据/异常三种状态视觉表现统一。
- 原有数据展示、实时刷新、配置读写功能全部无回归。
